# Dang et al. (2025) Replication Project
A replication and extension project of an experiment analyzing gratitude interventions and their effects on well-being. This replication was completed as a part of the PSYC 201A Statistical Computing and Inference from Data I course at UC San Diego during the Fall of 2026.



> **Original Publication:**\
> Dang, A. V., Coles, N. A., Oishi, S., & McCullough, M. E. (2026). The efficacy of seven gratitude interventions for promoting subjective well-being. *The Journal of Positive Psychology*, *21*(3), 517–535. https://doi.org/10.1080/17439760.2025.2502483

```

┣━━ data
┣━━ original_paper
┃   ┗━━ original_paper.pdf

┃   ┃   ┗━━ ProposedSEM.png

┃   ┣━━ Replication-Report-Template.pdf
┃   ┗━━ .gitignore

```
Data is stored in `./data`, the original paper that this work is based on is available as a pdf in `./original_paper/original_paper.pdf`. For the replication report, that is under the `./writeup` folder.
`./index.html` is the HTML file which contains the JavaScript script (jsPsych) experiment for data collection.
